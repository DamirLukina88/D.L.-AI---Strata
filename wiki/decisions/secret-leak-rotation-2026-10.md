# Public Secret Leak and Rotation (2026-10-13)

## Summary

- 2026-10-13: Four secrets were hardcoded as fallbacks in tools/dl_cli.py and tools/run-code-session.sh and pushed to the public fork DamirLukina88/D.L.-AI---Strata: STRATA_API_KEY, EXA_API_KEY, CONTEXT7_API_KEY, CLIENT_IP_ENCRYPTION_KEY (see private/.env for current values).
- Strata and client-IP keys rotated the same day (old Strata key verified 401 locally and through the tunnel). Exa and Context7 keys must be regenerated by the user in their dashboards.
- All secrets now live in ~/.config/dl-ai/secrets.env (mode 600), loaded by systemd (EnvironmentFile), fish, bash and dl_cli.load_env_file(); the model configs carry no api_key.
- History scrubbed with git filter-repo --replace-text limited to our own refs (--refs main dl/... ^upstream/main): a whole-repo run also rewrote upstream's GitHub-signed merge commits and broke the merge base. Backup bundle: ~/strata-pre-scrub-20261013.bundle (contains the old secrets; delete after the force-push).
- Gotcha: tools/strata_bench.py reads STRATA_KEY (not STRATA_API_KEY) or the config's api_key.
- Prevention: tools/pre-commit-scan-secrets.py hook; dl_auditing now catches environ.get('..KEY', '<literal>'), ${KEY:-literal} and ctx7sk- keys. Files with fake keys for tests carry the marker 'scan-secrets: fake-fixtures'.
- 2026-10-13 (later): The user regenerated the Exa and Context7 keys; the new ones are in secrets.env, private/.env and Antigravity's mcp_config.json, and both were verified working through the session daemon. All four leaked keys are now dead or replaced.
- 2026-10-13 (later): Force-pushed the scrubbed history to the fork (main 20142315 -> 51fae4a6, with --force-with-lease) and deleted the backup bundle. GitHub still serves the old commits by SHA until its own garbage collection (the API returned 200 for 20142315); only GitHub Support can purge them sooner. All four keys in them are rotated, so they are dead.
